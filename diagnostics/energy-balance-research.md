# Проверка энергетического баланса тонкого листа

Дата проверки: 2026-08-02
Ветка: `energy-balance-rework`

## Принятая модель

Пластина считается плоским проводящим листом нулевой геометрической толщины. Поле `u` непрерывно, а скачок нормальной производной задаёт единственный поверхностный ток `J`:

```text
u_s = i/4 * integral J(t) H0^(2)(kR) dt
du_above/dz = du0/dz + J/2
du_below/dz = du0/dz - J/2
```

Следовательно,

```text
du_above/dz - du_below/dz = J.
```

Для временной и волновой конвенции программы условие резистивного листа имеет вид

```text
u = q J
q = -i Zs / (k Z0)
Z0 = mu0 c.
```

При `Zs = (1+i) pi mu0 f delta`:

```text
q = delta/2 * (1-i),
(S - q I) J = -u0.
```

Это модель нулевого токового листа. Модель материальной пластины конечной толщины с двумя независимыми поверхностями потребовала бы других двухсторонних граничных условий и дополнительных неизвестных.

## Найденная ошибка масштаба

На каждой пластине используется координата `tau` и полудлина `h`:

```text
x = center + h*tau,
J(x) = phi(tau) / sqrt(1-tau^2),
dx = h dtau.
```

Однослойный потенциал и его квадратура уже использовали именно эту плотность. Однако до проверки от 2026-08-02 скачок производной, импедансный член и энергия тока вычислялись как

```text
J_wrong = phi(tau) / (h*sqrt(1-tau^2)).
```

Для стандартных пластин длиной `1` полудлина равна `0.5`, поэтому ток завышался в два раза, а дальнеполевая энергия примерно в четыре раза. Исправление выполнено одинаково в C#, C++ и CUDA. Версия протокола нативного решателя повышена до `thin_sheet_v2`, чтобы программа не принимала старые исполняемые файлы.

## Какие энергии сравниваются

Плотность знакового потока:

```text
Fz = -1/2 Im(conj(u) du/dz).
```

Падающая энергия считается только по геометрической проекции пластин:

```text
I_plate = 1/2 k |sin(theta)| sum(Lp).
```

### Рассеянное поле

Вверх и вниз интегрируется только поле `u_s`, созданное поверхностным током. Для однослойного потенциала на плоскости `z=0` его угловая диаграмма зеркально симметрична:

```text
R_scat = integral_upper |u_s^far|^2,
T_scat = integral_lower |u_s^far|^2,
R_scat = T_scat >= 0.
```

Здесь `T_scat` означает переднюю рассеянную компоненту. Это именно две величины, которые должны быть близки для принятой модели и обе должны ослабевать вместе с поверхностным током.

### Полное поле и ЗСЭ

На самой пластине дополнительно проверяются полные знаковые потоки:

```text
P_in = поток, входящий со стороны падения,
P_opposite = знаковый поток с противоположной стороны,
A_flux = P_in - P_opposite,
D = I_plate - P_in.
```

Поглощение вычисляется независимо:

```text
A_J = -1/2 Im(q) integral |J|^2 dx,
A_u = -1/2 Im(q)/|q|^2 integral |u|^2 dx.
```

Локальная проверка ЗСЭ:

```text
A_flux = A_J,
I_plate = D + P_opposite + A_J.
```

`P_opposite` является знаковым потоком через открытую конечную область. Из-за интерференции и переноса энергии около кромок он может быть немного отрицательным. Это не отрицательная прошедшая рассеянная энергия `T_scat`.

Независимая глобальная проверка:

```text
integral_contour F_total . n ds + A_J = 0.
```

## Численный результат после исправления

Две пластины `[-1.5,-0.5]` и `[0.5,1.5]`, `lambda=1`, `theta=45 deg`, `N=30`:

| delta | R_scat / I, % | T_scat / I, % | D / I, % | P_opposite / I, % | A_J / I, % | невязка ЗСЭ, % |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 108.20 | 108.20 | 100.00 | -0.00 | 0.00 | 0.00 |
| 0.001 | 106.19 | 106.19 | 98.31 | -0.38 | 2.02 | 0.05 |
| 0.01 | 92.80 | 92.80 | 86.21 | -1.26 | 14.98 | 0.06 |
| 0.05 | 57.86 | 57.86 | 54.06 | 6.23 | 39.66 | 0.05 |
| 0.1 | 36.03 | 36.03 | 33.80 | 18.98 | 47.18 | 0.04 |
| 0.2 | 17.51 | 17.51 | 16.49 | 38.68 | 44.81 | 0.02 |

Основные наблюдения:

1. `R_scat` и `T_scat` неотрицательны, совпадают до машинной точности и монотонно уменьшаются на проверенной серии.
2. При `delta=0.01` прежние дальнеполевые значения около `324.64%` уменьшились до `92.80%` после устранения лишнего множителя `1/h`.
3. Отрицательное значение `-1.26%` относится только к локальному знаковому потоку полного поля. Оно больше не выводится как прошедшая энергия.
4. Локальная невязка ЗСЭ не превышает `0.06%` в этой серии.
5. Значение рассеяния выше `100%` при идеальном листе допустимо: нормировка выполнена на геометрическую проекцию конечных пластин, поэтому результат является эффективностью сечения, а не вероятностью.

Для строки `delta=0.01` независимая невязка замкнутого контура равна примерно `0.26%` от `I_plate`.

Дополнительная сетка `theta = 15, 30, 45, 60, 90 deg`, `delta = 0, 0.001, 0.01, 0.05, 0.1, 0.2`, `N=30` также дала неотрицательные и монотонно убывающие `R_scat` и `T_scat`. Максимальное расхождение двух половин было на уровне машинного округления, максимальная локальная невязка ЗСЭ составила `0.08%`.

## Проверки

Автоматические тесты контролируют:

- отсутствие лишнего множителя полудлины в плотности тока;
- совпадение управляемого C# и нативного C++ решателей;
- неотрицательность и равенство верхней и нижней рассеянных энергий;
- равенство потоков рассеянного поля непосредственно сверху и снизу листа;
- убывание обеих рассеянных компонент в серии по `delta`;
- локальный и замкнутый энергетические балансы для одной и двух пластин.

## Итог

В интерфейсе и CSV основными результатами теперь являются `R_scat` и `T_scat`. Локальные величины полного поля переименованы в `IncidentSideDeficit` и `OppositeSideSignedFlux` и оставлены только для диагностики ЗСЭ. Это устраняет смешение физически разных величин без обрезания или искусственной перенормировки результатов.
