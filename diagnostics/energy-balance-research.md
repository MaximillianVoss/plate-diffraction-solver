# Проверка энергетического баланса тонкого листа

Дата проверки: 2026-08-01
Ветка: `energy-balance-rework`

## Принятая модель

Пластина считается плоским проводящим листом нулевой геометрической толщины. Поле `u` непрерывно, а нормальная производная имеет скачок, задающий поверхностный ток `J`.

Для используемого представления

```text
u_s = i/4 * integral J(t) H0^(2)(kR) dt
```

следы производной имеют знаки

```text
du_above/dz = du0/dz + J/2
du_below/dz = du0/dz - J/2
```

Поэтому `du_above/dz - du_below/dz = J`. Для временной и волновой конвенции программы условие тонкого резистивного листа записывается как

```text
u = q J
q = -i Zs / (k Z0)
Z0 = mu0 c
```

При `Zs = (1+i) pi mu0 f delta` получается

```text
q = delta/2 * (1-i)
```

Матричное уравнение:

```text
(S - q I) J = -u0
```

Старые добавки `IncidentBoundaryScale`, член с `du0/dz` в правой части и одностороннее условие Леонтовича удалены. Они смешивали объемную границу и лист нулевой толщины.

## Энергетические формулы

Нормированный знаковый поток вдоль оси `z`:

```text
Fz = -1/2 Im(conj(u) du/dz)
```

Падающая энергия считается только на геометрической проекции пластин:

```text
I_plate = 1/2 k |sin(theta)| sum(Lp)
```

При падении сверху:

```text
P_in  = -integral F_above dx
P_out = -integral F_below dx
A_flux = P_in - P_out
```

Для падения снизу знаки автоматически меняются. Отдельное импедансное поглощение:

```text
A_J = -1/2 Im(q) integral |J|^2 dx
A_u = -1/2 Im(q)/|q|^2 integral |u|^2 dx
```

Пассивный лист имеет `Im(q) < 0`, поэтому обе формулы неотрицательны. Проверяемое локальное тождество:

```text
A_flux = A_J
```

Для удобства отчета определены знаковые величины

```text
R_net  = I_plate - P_in
T_full = P_out
I_plate = R_net + T_full + A_J
```

`R_net` и `T_full` относятся к открытой области самих конечных пластин. Из-за бокового переноса энергии около кромок они не обязаны быть двумя неотрицательными дальнеполевыми энергиями.

Независимая глобальная проверка выполняется на замкнутом контуре:

```text
integral_contour F_total . n ds + A_J = 0
```

## Численный результат

Одна пластина `[-1,1]`, `lambda=1`, `theta=45 deg`, `N=35`:

| delta | R_net / I | T_full / I | A_J / I | локальная невязка / I |
|---:|---:|---:|---:|---:|
| 0 | 1.000000 | 0.000000 | 0.000000 | < 0.000001 |
| 0.001 | 0.989015 | -0.000883 | 0.011613 | 0.000254 |
| 0.01 | 0.902008 | 0.000232 | 0.097382 | 0.000378 |
| 0.05 | 0.634809 | 0.066977 | 0.297881 | 0.000332 |
| 0.1 | 0.441239 | 0.177888 | 0.380608 | 0.000265 |
| 0.2 | 0.252247 | 0.360915 | 0.386650 | 0.000187 |

Для `delta=0.01` независимая невязка замкнутого контура составляет около `0.18%` от `I_plate`.

Небольшое отрицательное `T_full` при очень малом `delta` не обрезается: это знаковый поток через открытую проекцию конечной пластины. Он уменьшается при уточнении дискретизации и не нарушает локальное тождество потоков.

## Рассеянное дальнее поле

`CalculateFarFieldScatteredEnergy` интегрирует только `|u_s|^2`. Для однослойного потенциала на `z=0` верхняя и нижняя рассеянные энергии одинаковы. Обе уменьшаются при увеличении `delta`, поскольку ток и рассеянное поле ослабевают.

Эти величины нельзя подставлять как полные `R` и `T`: полное прошедшее поле содержит падающую волну и интерференционный вклад. При малом угле `theta` геометрическая энергия `I_plate` мала, поэтому эффективность рассеяния, нормированная на нее, может превышать 100%. Это сечение рассеяния, а не вероятность.

## Итог

1. Падающая энергия теперь относится только к пластинам, а не к прямоугольному контуру.
2. Потоки сверху и снизу доступны отдельно и согласуются с импедансным поглощением.
3. ЗСЭ не закрывается искусственной перенормировкой.
4. Полное прохождение и прошедшая рассеянная энергия выводятся раздельно.
5. При росте скин-слоя `R_net` падает, `T_full` растет, а обе рассеянные компоненты дальнего поля падают.
