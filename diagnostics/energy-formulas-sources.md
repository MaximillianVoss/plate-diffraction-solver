# Источники и вывод формул энергетики

Дата: 2026-08-01
Модель: плоский проводящий лист нулевой толщины

## Что моделируется

В задаче используется не объемный проводник с двумя независимыми границами, а резистивный лист. На нем непрерывна тангенциальная компонента электрического поля, а скачок магнитного поля задает поверхностный ток.

Общий вид условия:

```text
E_t = Zs Js
```

Стандартная средняя мощность потерь:

```text
P_loss = 1/2 Re(Zs) |Js|^2
```

Источники по физическому смыслу поверхностного импеданса:

- Sergey Yuferev, Nathan Ida, [Surface Impedance Boundary Conditions: A Comprehensive Approach](https://www.routledge.com/Surface-Impedance-Boundary-Conditions-A-Comprehensive-Approach/Yuferev-Ida/p/book/9781420044898).
- [Surface Impedance Boundary Conditions, ICS technical article](https://www.compumag.org/wp/wp-content/uploads/2018/08/ICS212-technical-article.pdf#page=2).
- UC Berkeley EECS, [RFIC Lecture 2, conductor loss and surface resistance](https://rfic.eecs.berkeley.edu/courses/ee217sp05/lect2.pdf#page=22).

## Переход к переменным программы

Рассеянное поле представлено однослойным потенциалом:

```text
u_s = i/4 * integral J(t) H0^(2)(kR) dt
```

Для этой конкретной конвенции:

```text
du_above/dz = du0/dz + J/2
du_below/dz = du0/dz - J/2
```

Из уравнений Максвелла поверхностный ток пропорционален `-iJ/(omega mu)`. Поэтому:

```text
u = qJ
q = -i Zs/(k Z0)
Z0 = mu0 c
```

При принятой модели скин-слоя

```text
Zs = (1+i) pi mu0 f delta
q = delta/2 (1-i)
```

Знак перед `i` определяется одновременно временной конвенцией, выбором `H0^(2)` и знаком скачка производной. Его нельзя переносить из формулы для `H0^(1)` без проверки.

## Поглощение

В нормировке скалярного потока программы:

```text
A_J = -1/2 Im(q) integral |J|^2 dx
```

Из `u=qJ` получается независимая контрольная форма:

```text
A_u = -1/2 Im(q)/|q|^2 integral |u|^2 dx
```

Совпадение `A_J` и `A_u` проверяет граничное условие. В самом тонком случае с краевой сингулярностью расхождение уменьшается при росте `N`: в контрольном расчете примерно с `8.1%` при `N=30` до `4.4%` при `N=50`.

## Потоки и ЗСЭ

Знаковый нормальный поток:

```text
Fz = -1/2 Im(conj(u) du/dz)
```

Падающий поток только на пластины:

```text
I_plate = 1/2 k |sin(theta)| sum(Lp)
```

Разность следов потока дает поглощение:

```text
A_flux = P_in - P_out = A_J
```

Глобальная независимая проверка:

```text
integral_contour F_total . n ds + A_J = 0
```

Падающая плоская волна сама по себе имеет нулевой знаковый поток через любой замкнутый контур. Поэтому старое суммирование только положительных частей потока по сторонам прямоугольника не является строгим выводом `I/R/T`.

## Дальнее поле

Для уравнения Гельмгольца и дальнеполевого представления:

- Rainer Kress, [Boundary Integral Equations in Time-Harmonic Acoustic Scattering](https://users.flatironinstitute.org/~ahb/m126w12/public_html/Kress1991MCM_BIE_acoustic_scatt_numerics_review.pdf#page=8).
- Rainer Kress, [Inverse scattering from an open arc with generalized impedance boundary conditions](https://num.math.uni-goettingen.de/kress/gibc.pdf#page=13).

Интеграл `|u_s|^2` дает энергию только рассеянной волны. Полное прошедшее поле равно сумме падающего и рассеянного полей, поэтому включает интерференционный член. По этой причине:

- `T_scat^far` и `T_full` являются разными величинами;
- `R_scat^far + T_scat^far + A` нельзя приравнивать к `I_plate`;
- нормированное рассеяние может быть больше 100%, особенно при скользящем падении, поскольку это эффективность относительно геометрической проекции.

## Формулировка для преподавателя

Пластина заменена тонким импедансным листом. Падающий поток интегрируется только по ее геометрической проекции. Сверху и снизу вычисляются точные следы нормальной производной, а их энергетическая разность сравнивается с независимым поглощением через поверхностный ток. Дополнительно проверяется полный знаковый поток через замкнутый контур. Рассеянное дальнее поле выводится отдельно и не смешивается с полным прошедшим полем.
