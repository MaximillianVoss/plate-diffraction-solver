# WPF-интерфейс расчёта одной пластины

Приложение выполняет численный расчёт дифракции на одной тонкой пластине через `Diffraction.Core`. После изменения входных параметров нажмите `Рассчитать`: карточки, таблицы, графики и карты поля обновляются одним согласованным результатом.

## Запуск

Требуются Windows и среда выполнения .NET 9 Desktop.

Из корня проекта запустите `ЗАПУСТИТЬ.bat`: он собирает и открывает актуальную WPF-версию для одной пластины.

```powershell
dotnet run --project Diffraction.WpfPrototype
```

При открытии `Diffraction.sln` профиль `WPF — одна пластина` запускает тот же проект.
Старое WinForms-приложение остаётся отдельным и не используется этим ярлыком.

## Что рассчитывается

- решение без скин-слоя и со скин-слоем методом коллокации;
- решение со скин-слоем методом Галеркина;
- коэффициенты обоих методов и модуль их разности;
- полное поле `u`, сечение `Re u(x, λ/10)` и карты `|u|`;
- сравнение Галеркина и коллокации на одной пластине;
- `R_scat`, `T_scat`, `A_J`, потоки у листа и локальная невязка ЗСЭ;
- невязка граничного условия отдельно для коллокации и Галеркина;
- серии по толщине скин-слоя и углу падения.

До первого запуска числовые области остаются пустыми. История содержит только расчёты, выполненные в текущем сеансе, и хранит вместе с параметрами соответствующий результат.

## Ограничения

- WPF-интерфейс сейчас работает в режиме одной пластины на CPU;
- CUDA-модуль и режим двух пластин остаются в исходном WinForms-приложении;
- сохранение пакета экспорта из WPF пока отключено, таблицы можно копировать через контекстное меню;
- результаты серий строятся на единообразной контрольной квадратуре, основной одиночный результат рассчитывается на более плотной сетке.

Актуальные проверки перечислены в [testing-report.md](testing-report.md).
